# Support

Start with the [README](README.md), including its quickstart, configuration, document
format, MCP, and development sections.

Open a GitHub issue for:

- a reproducible bug
- a documentation problem
- a clearly scoped feature request
- a compatibility question not answered by the README

Include the Automation Miner version or commit, Python version, operating system,
command or MCP request, expected behavior, actual behavior, and relevant sanitized
logs.

Do not post API keys, confidential source documents, generated mining workspaces, or
security vulnerabilities. Report vulnerabilities according to
[SECURITY.md](SECURITY.md).
